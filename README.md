# K-Local Atlas : 골목의 주파수 (Alleyway Frequency 3D)
**Korea Local Marketing Hackathon 2026 (HACK:ON × ElevenLabs × Trip-Pups)**
- **Live Web App (MVP)**: https://kevin9327.github.io/k-local-atlas/
- **Core Features**:
  1. **Dual-Engine Interactive Map**: Three.js 3D Isometric Alleyway Diorama + Real GPS OpenStreetMap (Leaflet) with Naver Map & Google Maps deep links.
  2. **4-Language AI Voice Docent (`EN / 日本語 / 中文 / 한국어`)**: Pre-rendered studio MP3 voice guides across 6 authentic Korean neighborhood micro-courses (24 local spots) + Live ElevenLabs Multilingual v2 API synthesizer + WebAudio procedural alleyway soundscape mixer.
  3. **Trip-Pups Pet-Friendly Verification & Korean Owner Ordering Passport**: One-tap native Korean audio survival cards (`사장님께 보여드리기 & 음성 재생`) and `.GPX` route export.
